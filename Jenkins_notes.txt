1️⃣ What is Jenkins (in YOUR project terms)

Jenkins = Automation server

For your billing app, Jenkins will:

✔ Pull latest code from Git
✔ Build Spring Boot (Maven)
✔ Build React (npm)
✔ Create Docker images
✔ Run docker-compose
✔ Restart containers automatically

👉 Instead of you manually running:
git pull
mvn clean package
npm run build
docker-compose down
docker-compose up --build

  --name jenkins \
  -p 8080:8080 \
  -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  -v /var/run/docker.sock:/var/run/docker.sock \

“SCM stands for Source Code Management. Jenkins integrates with Git-based SCM systems to fetch code and Jenkinsfile directly from the repository, enabling pipeline-as-code.”

Docker Needs to be installed inside JENKINS Container.

We need to:

Install Docker CLI inside Jenkins container

Allow Jenkins user to use Docker

Restart Jenkins

docker stop jenkins
docker rm jenkins

docker run -d \
  --name jenkins \
  -p 9001:8080 \
  -p 50000:50000 \
  -v jenkins_home:/var/jenkins_home \
  -v /var/run/docker.sock:/var/run/docker.sock \
  --group-add $(getent group docker | cut -d: -f3) \
  jenkins/jenkins:lts

// enter as root user
docker exec -it -u root jenkins bash
apt-get update
apt-get install -y docker.io
exit

docker restart jenkins




Jenkins runs as jenkins user, not root

Root success ≠ Jenkins success

PATH issues are extremely common in CI

SCM was never the problem after workspace cleanup
